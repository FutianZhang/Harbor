# 项目背景

某果品供应链企业拟评估猕猴桃采后处理方案。现有材料包括采后小试测定、表型图像、采购与储运经营记录、处理成本样例，以及科研和监管资料。管理层需要判断现有证据能否支持进入下一阶段验证，并评估对供应链及经营的效益。

你是该企业采后技术与供应链经营负责人，需要向研发、质量、合规、冷链、采购、品类经营和财务团队提交决策材料。

# 可用材料

- `/app/input_files/实验资料/`：多项采后指标工作簿、表型图像及跨期证据更新记录。
- `/app/input_files/企业经营数据样例/`：采购、库存、报损折价、销售、冷链、质检、处理成本和渠道动销记录。

涉及数量、时间、单位和金额时，应采用可追溯的原始记录，并说明使用口径；涉及公开证据时，应区分可核验事实、研究推断、监管背景和本项目假设。

# 工作任务

1. 复核采后小试数据，判断处理组与对照组在成熟进程和品质指标上的差异，并说明统计证据的适用范围。
2. 结合表型图像和自行检索的科研证据，说明证据的适用范围及向品种、批次和冷链场景外推的条件。
3. 对采购、库存、损失、销售、冷链、质检、成本和渠道数据进行口径整理与必要对账，建立经营基线。
4. 构建可调整的经营情景，估计损失、折价、退货、可售窗口和新增成本变化对项目价值的影响；假设与事实须分开呈现。
5. 自行检索并核对标准、登记、标签和监管资料的现行状态及适用范围，明确研发验证与商品化应用之间的条件。
6. 提出下一阶段的验证路线、阶段建议和数据记录等要求，并给出继续、暂缓或终止的当前决策建议。

# 交付物

提交以下文件：

- `/app/output/猕猴桃采后GA3处理验证及供应链应用评估报告.docx`
- `/app/output/猕猴桃采后GA3处理分析与应用测算底稿.xlsx`

报告应便于管理层阅读，包含结论、证据、经营影响、合规边界和行动建议。测算底稿应保留来源索引、原始数据、统计分析、经营对账、情景假设和决策门槛，并支持后续调整。

# 硬性要求

不得补写材料中无法核验的试验条件、产品登记状态、残留结论、经营收益或其他事实。

测算底稿中的派生指标和情景结果应由公式联动。

交付物之间的关键数值、口径、结论和建议应保持一致。

正文不得出现本地路径、`/app/`路径、占位符、制作说明或与业务内容无关的文字。
