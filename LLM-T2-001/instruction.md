# 项目背景

某果蔬采后技术团队拟将5 mT静磁场处理的草莓冷藏小试扩展到多基地、多品种、跨产季、商业冷库和运输场景。项目已形成小试测量、表型图、试验设计、设备与环境控制、批次经营台账和阶段治理资料，需要据此完成确证验证方案、效果评价和部署决策材料。

你是该项目的试验评估与应用转化负责人，负责统筹研发、统计、质量、设备、运营和财务信息，向项目委员会提交正式报告与可复算分析底稿。

# 可用材料

- `/app/input_files/硬度 (Hardness, N).xlsx`：用于评价0 mT对照组和5 mT处理组在各冷藏时点的硬度变化。
- `/app/input_files/失重率 (Weight loss, %).xlsx`：用于评价两组在各冷藏时点的失重变化。
- `/app/input_files/水溶性果胶 (WSP, mg-g).xlsx`：用于评价两组在各冷藏时点的水溶性果胶变化。
- `/app/input_files/多聚半乳糖醛酸酶活性 (PG activity, U-kg).xlsx`：用于评价两组在各冷藏时点的PG活性变化。
- `/app/input_files/颜色 L★ (亮度).xlsx`：用于评价两组在各冷藏时点的亮度变化。
- `/app/input_files/颜色 a★ (红绿度).xlsx`：用于评价两组在各冷藏时点的红绿度变化。
- `/app/input_files/总色差 ΔE.xlsx`：用于评价两组在各冷藏时点的综合色差变化。
- `/app/input_files/文献一表型图.png`：用于核对两组在各冷藏时点的外观表现。
- `/app/input_files/草莓静磁场冷藏试验与经营输入.xlsx`：项目主数据工作簿，包含小试整理、指标与证据索引、基地与批次覆盖、样本量、因子设计、随机化盲法、设备测场、环境采集、端点、样本链路、统计计划、经营门槛、风险、阶段评审、RCA和部署SOP。

# 工作任务

1. 复核小试设计、原始测量和表型资料，评价0 mT对照组与5 mT处理组在冷藏期间的品质变化。
2. 按项目主数据形成多基地确证验证设计，覆盖品种、产季、独立批次、处理因素、包装、温度和运输条件。
3. 复核样本量与损耗冗余，建立分层区组随机、三级盲码、样本链路、偏差缺失规则和数据锁库要求。
4. 形成设备版本锁定、三维测场、温升、电磁兼容、校准、能耗以及冷库和运输环境同步采集方案。
5. 为主要终点、支持性终点和商品性终点配置统计模型，报告效应量、置信区间、模型诊断、多重性和敏感性分析。
6. 复核批次、库存和销售台账，建立货架期、放行、报损、售价、能耗、维修和折旧的经营测算及投资门槛。
7. 建立风险台账、阶段门、批次与阶段评审、关键失败RCA、部署SOP和继续、限定或停止决策。
8. 保持报告与分析底稿在关键数字、公式、证据位置、风险状态、阶段门和决策建议上的一致性。

# 交付物

提交以下文件：

- `/app/output/草莓静磁场冷藏数据分析与验证底稿.xlsx`

报告应适合项目委员会、研发、质量、运营和财务团队共同评审，覆盖小试结果、确证设计、设备环境、统计计划、经营测算、风险、阶段门、RCA、部署SOP和决策建议。

分析底稿应保留原始数据、证据位置、计算公式、设计矩阵、样本量复核、设备环境控制、统计模型、经营复核、阶段评审和跨产物核对，并支持参数调整与后续批次更新。

# 硬性要求

小试测量、确证计划、设备放行状态和经营预算应按各自的数据属性呈现。

派生指标、对账结果、样本量和经营测算应由公式或可复核计算过程形成；原始测量不得用手工汇总值替代。

证据定位至少达到文件、工作表或图像区域、单元格范围的粒度。

交付物之间的关键数值、口径、阶段状态和决策建议应保持一致。

文件名和格式必须与交付物清单一致，不得提交额外文件。

正文不得出现本地路径、`/app/`路径、占位符、制作说明或与项目内容无关的文字。
